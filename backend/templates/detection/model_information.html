Input Features

Features used to represent the characteristics of Ethereum transactions during model prediction.

01

From Address

Encoded wallet address that initiates the Ethereum transaction.

02

To Address

Encoded wallet address that receives the Ethereum transaction.

03

Transaction Value

The value transferred through the Ethereum transaction.

04

Block Height

Blockchain block position associated with the transaction.

05

Hour

The transaction execution hour extracted from the timestamp.

Evaluation Metrics

Metrics used to evaluate classification performance on the Ethereum transaction dataset.

Precision

Measures the proportion of transactions predicted as anomalies that are actually anomaly-indicating.

Recall

Measures the proportion of actual anomaly-indicating transactions successfully detected by the model.

F1 Score

Harmonic mean of precision and recall, providing a balance between the two measures.

PR-AUC

Measures classification performance across different precision-recall thresholds.

MCC

Measures binary classification quality using all four components of the confusion matrix.

Specificity

Measures the proportion of normal transactions correctly classified as normal.
